1. INTRODUCTION                                                *vimf90-intro*

|vimf90| turns Vim / Neovim into a modern, responsive IDE for Fortran 90+.

Key Features:
  * First-class Fortran Package Manager (|fpm|) integration (`build`, `run`, `test`, `new`).
  * Intelligent multi-file project management: root detection (`fpm`, `CMake`, `Meson`, `Make`),
    automatic module search path (`-I`, `-J`) resolution, and project-wide Universal Ctags.
  * Smart Fortran construct completion (`program`, `module`, `subroutine`,
    `function`, `if-then`, `do`, `block`, `type`, `select case`, `interface`, etc.).
  * Non-blocking asynchronous compilation and linking using Vim 8/9 jobs and
    Neovim async jobs.
  * Direct QuickFix integration with compiler errorformat support for
    GNU Fortran (`gfortran`), Intel (`ifort`, `ifx`), NVIDIA (`nvfortran`),
    and LLVM (`flang`).
  * Automated formatting via `fprettify` or built-in whitespace rules.
  * Strict buffer isolation: all mappings and settings are buffer-local (`<buffer>`)
    with full |b:undo_ftplugin| support.

2. INSTALLATION                                              *vimf90-install*

Using vim-plug: >
    Plug 'rudrab/vimf90'
<
Using lazy.nvim (Neovim): >
    { 'rudrab/vimf90', ft = { 'fortran' } }
<
Using Vundle: >
    Plugin 'rudrab/vimf90'
<
Python Dependencies:
For automated formatting and language server capabilities, `fprettify` and
`fortls` can be installed automatically by running: >
    :FortranInstallDeps
<
or via pip: >
    pip install fprettify fortran-language-server
<

3. CONFIGURATION OPTIONS                                     *vimf90-options*

*g:fortran_leader*
    Leader key used for default vimf90 mappings.
    Default: "`" (backtick) or |mapleader|

*g:fortran_compiler*
    Fortran compiler executable.
    Default: "gfortran" (supports "ifx", "ifort", "nvfortran", "flang", etc.)

*g:fortran_fcflags*
    Compiler flags for compiling object files.
    Default: "-Wall -O0 -c"

*g:fortran_flflags*
    Compiler/linker flags for creating executables.
    Default: "-Wall -O0"

*g:fortran_exeExt*
    Executable file extension (e.g. ".exe" on Windows, "" on Linux/macOS).
    Default: ""

*g:fortran_async*
    Enable asynchronous non-blocking compilation for Vim 8+ and Neovim.
    Default: 1

*g:fortran_run_terminal*
    Run executables, fpm apps, and debuggers in a bottom terminal split instead of external shell.
    Default: 0

*g:fortran_linter*
    Formatting mode on buffer save:
      0 : On-the-fly insert mode whitespace adjustment.
      1 : Built-in regex whitespace formatting on save (default).
      2 : Format with `fprettify` on save.
     -1 : Disable automatic formatting.

*g:fprettify_options*
    Options passed to `fprettify` when `g:fortran_linter = 2`.
    Default: "--silent"

*g:fortran_completer*
    Key mapped to complete Fortran constructs.
    Default: "<F3>"

*g:fortran_update_timestamp*
    Automatically update `! Last Modified: ...` header comments on save.
    Default: 1

4. COMMANDS                                                 *vimf90-commands*

All commands are buffer-local and available in Fortran buffers:

*:FortranCompile*
    Compiles current buffer to an object file (`.o`), auto-resolving project include paths.

*:FortranExe*
    Compiles and links current buffer to an executable.

*:FortranRun*
    Builds and runs the current buffer's executable.

*:FortranArgs*
    Prompts for command-line arguments to pass when executing the binary.

*:FortranDebug*
    Builds with debug flags (`-g`) and starts the debugger (`gdb` or `lldb`).

*:FortranMake*
    Executes `:make` with configured make arguments.

*:FortranMakeArgs*
    Prompts for make properties/targets.

*:FortranMakeProj*
    Interactively generates standard Fortran project directory structure (`src/`, `help/`, `Makefile`).

*:FortranFormat*
    Formats current buffer using the active formatter (`fprettify` or regex).

*:FortranInstallDeps*
    Installs recommended Python tooling (`fprettify`, `fortls`).

*:FortranFpm* [subcommand]
    Runs an `fpm` command (with tab-completion for `build`, `run`, `test`, `new`, `clean`, etc.).

*:FortranFpmBuild* [args]
    Runs `fpm build` asynchronously from the project root.

*:FortranFpmRun* [args]
    Runs `fpm run` from the project root.

*:FortranFpmTest* [args]
    Runs `fpm test` from the project root.

*:FortranFpmNew* [name]
    Initializes a new Fortran Package Manager project.

*:FortranProjectBuild* [args]
    Automatically builds the project using detected build system (`fpm`, `cmake`, `make`).

*:FortranProjectRoot*
    Displays the detected project root directory.

*:FortranTags*
    Generates / updates Universal Ctags across the entire Fortran project.

*:FortranFindModule* [name]
    Searches the project for the file defining `module <name>` and opens it.

5. KEY MAPPINGS & <PLUG> TARGETS                            *vimf90-mappings*

Default shortcuts (using `<Leader>` or `g:fortran_leader`):

  Normal Mode      Target                            Action
  ----------------------------------------------------------------------------
  `<leader>cc`     <Plug>(vimf90-compile)            Compile object file
  `<leader>ce`     <Plug>(vimf90-exe)                Generate executable
  `<leader>cr`     <Plug>(vimf90-run)                Build & Run executable
  `<leader>cl`     <Plug>(vimf90-cla)                Set command line arguments
  `<leader>cd`     <Plug>(vimf90-dbg)                Debug executable
  `<leader>mk`     <Plug>(vimf90-make)               Run Makefile
  `<leader>mp`     <Plug>(vimf90-makeprop)           Set make parameters
  `<leader>gp`     <Plug>(vimf90-makeproj)           Generate project scaffolding
  `<leader>fb`     <Plug>(vimf90-fpm-build)          fpm build project
  `<leader>fr`     <Plug>(vimf90-fpm-run)            fpm run project
  `<leader>ft`     <Plug>(vimf90-fpm-test)           fpm test project
  `<leader>tg`     <Plug>(vimf90-tags)               Generate project Ctags
  `<leader>fm`     <Plug>(vimf90-find-module)        Find & jump to module
  `<F3>`           <Plug>(vimf90-construct-complete) Smart construct complete
                   <Plug>(vimf90-format)             Format current buffer

6. FORTRAN PACKAGE MANAGER (FPM)                                *vimf90-fpm*

|vimf90| provides first-class support for modern `fpm` (https://fpm.fortran-lang.org/).

When working inside an `fpm` repository (any folder containing `fpm.toml`),
|vimf90| automatically detects the project root.

  * `<leader>fb` or `:FortranFpmBuild`: Compiles the whole project asynchronously.
  * `<leader>fr` or `:FortranFpmRun`: Runs the project's executable application.
  * `<leader>ft` or `:FortranFpmTest`: Runs all unit tests.
  * `:FortranFpmNew my_lib`: Scaffolds a new standard Fortran library or app.

7. LARGE MULTI-FILE PROJECTS                               *vimf90-projects*

In 2026, Fortran projects often span hundreds of files across nested folders
with inter-module dependencies.

|vimf90| handles large projects through:
  1. Automatic Root Detection: Detects `fpm.toml`, `CMakeLists.txt`, `meson.build`,
     `Makefile`, or `.git` up the directory tree.
  2. Automatic Module Resolution: Discovers `.mod` and header directories across
     `src/`, `include/`, `build/`, `build/gfortran_*` and injects `-I` flags into
     single-file compile commands automatically.
  3. Universal Ctags: Run `<leader>tg` or `:FortranTags` to generate tags across all
     modules, subroutines, types, and interfaces in the repository.
  4. Module Navigation: Run `<leader>fm` or `:FortranFindModule <name>` to instantly
     jump to the file defining a module.

8. CONSTRUCT COMPLETION                                  *vimf90-constructs*

Pressing `<F3>` (or `g:fortran_completer`) at the end of a construct opening line
automatically generates the matching `end` statement and positions the cursor inside:

  Typed:                               Generated:
  ----------------------------------------------------------------------------
  `program my_app<F3>`                 program my_app
                                         <cursor positioned here>
                                       end program my_app

  `loop1: do i = 1, 100<F3>`           loop1: do i = 1, 100
                                         <cursor positioned here>
                                       end do loop1

  `type :: Particle<F3>`               type :: Particle
                                         <cursor positioned here>
                                       end type Particle

==============================================================================
9. FORMATTING & LINTING                                  *vimf90-formatting*

Set `let g:fortran_linter = 2` in `.vimrc` to enable automatic `fprettify`
formatting whenever you save a Fortran file.

You can also run `:FortranFormat` at any time on demand.

==============================================================================
10. ASYNCHRONOUS BUILD ENGINE                                 *vimf90-async*

When `g:fortran_async = 1` (default), running `:FortranCompile`, `:FortranExe`, or
`:FortranFpmBuild` spawns background jobs using Vim 8+ `job_start` or Neovim
`jobstart`. Output is parsed and streamed into the QuickFix window in the background
without freezing the editor.

==============================================================================
11. LANGUAGE SERVER PROTOCOL (LSP)                              *vimf90-lsp*

For coc.nvim, add the following configuration in your `coc-settings.json` or `.vimrc`: >
    let g:coc_user_config = {
          \   'languageserver': {
          \     'fortran': {
          \       'command': 'fortls',
          \       'args': ['--lowercase_intrinsics'],
          \       'filetypes': ['fortran'],
          \       'rootPatterns': ['fpm.toml', '.fortls', '.git/']
          \     }
          \   }
          \ }
<

==============================================================================
12. GUI MENU                                                    *vimf90-menu*

When running in GUI mode (gVim) with menu support enabled:
  * A top-level 'Fortran' menu appears automatically on Fortran buffers.
  * Dynamically shows exact expanded shortcuts (e.g. `\cc`, `,cc`, `<Space>cc`).
  * To enable dynamic standard/dialect naming (e.g. 'Fortran 2008', 'Fortran 2018'): >
      let g:fortran_menu_dynamic_dialect = 1
<
  * To customize the menu title manually: >
      let g:fortran_menu_name = '&Fortran'
<
